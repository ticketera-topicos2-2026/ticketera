# Bitácora del equipo

Registro del trabajo del equipo, en español (D-09, PLAN 6.6).

- Una entrada por semana en `AAAA-MM-DD-<tema>.md`, con la fecha del lunes de la semana o la del trabajo
  registrado; un grupo de tareas del bootstrap puede tener su propia entrada (`AAAA-MM-DD-grupo-N.md`).
- La evidencia (capturas, JSON exportados, salidas de comandos) va en `evidencia/<tema>/` y se enlaza desde la
  entrada.
- Cada entrada declara el uso de IA, como los pull requests (RB-05).

## Plantilla

```markdown
# AAAA-MM-DD · <tema>

- **Autor**: <nombre> (Integrante X)
- **Issue / pull request**: #n / #m

## Qué se hizo

- ...

## Decisiones tomadas

- D-xx: ... (aprobada / propuesta, pendiente de voto)

## Evidencia

- ...

## Pendientes

- ...

## Uso de IA

<Qué copilotos se usaron y para qué, o «No se usó IA».>
```
